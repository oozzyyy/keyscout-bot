# KeyScout

Telegram-бот, который следит за упоминаниями слов в российских СМИ. Пользователь задаёт слова
(компании, людей, темы) — бот собирает материалы 25 источников за последние 12 или 24 часа,
считает упоминания, оценивает тон новостей, пишет аналитическую выжимку и присылает отчёт
в чат или на почту. Внутри бота — веб-приложение (Telegram Mini App) с дашбордом, лентой
материалов и настройками.

## Возможности

- поиск по словам с вариантами написания: «клод» находит Claude, Anthropic, Claude Code;
  варианты подбирает языковая модель или их можно вписать вручную через «/» (`клод / claude`);
- отчёт-картинка: упоминания по словам и источникам, динамика по проверкам;
- выжимка по каждому слову: тон, суть, ключевые события со ссылками, что может влиять;
- автообновление с любым промежутком от 10 минут до 7 суток;
- отчёты на почту;
- веб-приложение: обзор с интерактивными графиками, лента с фильтрами, все настройки бота;
- журнал поисков в Excel для администратора.

## Устройство

```
Telegram ⇄ bot/ (Go) ──HTTP──▶ analyzer/ (Python, FastAPI)
Mini App ⇄    ├─ webapp/ + /api   ├─ сбор источников в SQLite
              └─ data.json        ├─ поиск, графики (matplotlib)
                 (настройки)      ├─ выжимка (DeepSeek или Claude)
                                  └─ письма (SMTP), журнал (Excel)
```

| Папка | Что внутри |
|---|---|
| `bot/` | Telegram-бот, настройки пользователей, API веб-приложения |
| `bot/webapp/` | веб-приложение (HTML, CSS, JS без сборки), встраивается в бинарник бота |
| `analyzer/` | сбор и поиск материалов, отчёты, выжимка, почта, журнал |
| `deploy/` | запуск на сервере без Docker и root |
| `assets/` | аватар бота |

Настройки пользователей хранит только бот (`bot/data.json`): чат и веб-приложение меняют их
через одно хранилище, поэтому изменения из приложения сразу видны в боте и наоборот.

## Источники

25 источников в `analyzer/sources.py`:

| Раздел | Источники |
|---|---|
| Новости | РИА Новости, АиФ, Интерфакс, Лента.ру, Известия, Российская газета |
| Бизнес | Коммерсантъ, vc.ru, РБК, Ведомости, The Bell, Frank Media, Банки.ру, RB.ru |
| Технологии | Хабр, 3DNews, CNews, iXBT, Ferra.ru, Overclockers, Хайтек+, Код Дурова, SecurityLab |
| Наука | N+1, Naked Science |

Пользователь включает и выключает их и может добавить свой сайт или RSS-ленту.

Поиск идёт по дате публикации ровно за выбранное окно. RSS-ленты хранят мало записей, поэтому
анализатор собирает материалы постоянно — при запуске и каждые 10 минут — и догружает пропуски
по картам сайтов (у vc.ru — через API ленты, у Хабра — по страницам раздела «Новости»).
Если окно ещё не собрано полностью, например сразу после первого запуска, отчёт пишет об этом.
Первый запуск на пустой базе занимает около 2 минут.

## Языковая модель

Варианты слов и выжимку пишет языковая модель (`analyzer/llm.py`), подходит любой из ключей:

- `DEEPSEEK_API_KEY` — DeepSeek, модель `deepseek-flash`; работает и с серверов в России;
- `ANTHROPIC_API_KEY` — Claude, модели `CLAUDE_MODEL` и `DIGEST_MODEL`.

Если заданы оба, используется Claude, `LLM_PROVIDER=deepseek` выбирает DeepSeek. Без ключа бот
тоже работает: тон оценивается по словарю, варианты — только вписанные вручную и для частых тем.
Подобранные варианты слов и выжимки кэшируются, повторно за них платить не нужно.

## Запуск

Нужны Go 1.24+ и Python 3.13.

```bash
cp .env.example .env
```

Впишите в `.env` токен бота от [@BotFather](https://t.me/BotFather) (`BOT_TOKEN`), при желании —
ключ языковой модели и SMTP для писем. Затем:

```bash
./run.sh
```

Скрипт создаст окружение Python, поставит зависимости, соберёт и запустит бота.

### Веб-приложение

Telegram открывает Mini App только по HTTPS. Для запуска с компьютера нужен туннель
[cloudflared](https://github.com/cloudflare/cloudflared) — бесплатно и без регистрации:

```bash
brew install cloudflared
```

```bash
./run.sh --tunnel
```

Скрипт поднимет туннель и передаст его адрес боту, бот сам поставит кнопку «Обзор» рядом
с полем ввода. Без `--tunnel` приложение открывается только локально: http://127.0.0.1:8080.

Чтобы видеть правки интерфейса без пересборки:

```bash
WEBAPP_DIR=$PWD/bot/webapp ./run.sh --tunnel
```

Каждый запрос к API приложения подписан Telegram (`Authorization: tma <initData>`): бот проверяет
подпись по `BOT_TOKEN` и её срок, поэтому пользователь видит и меняет только свои данные.

| Метод | Что делает |
|---|---|
| `GET /api/state` | настройки пользователя и каталог источников |
| `POST /api/settings` | изменить настройки |
| `POST /api/expand` | варианты написания слов |
| `GET /api/dashboard` | данные для обзора и ленты |
| `POST /api/report` | прислать отчёт в чат или на почту |

### Docker

```bash
docker compose up -d --build
```

Веб-приложение слушает `127.0.0.1:8080` хоста, наружу его выводит обратный прокси с HTTPS
(например, Caddy) или туннель. Публичный адрес задаётся в `.env` как `WEBAPP_URL`.

### Сервер без root и Docker

Скопируйте `deploy/start.sh` и `deploy/restart.sh` в корень проекта на сервере, рядом с `bot/`
и `analyzer/`. `start.sh` запускает туннель, анализатор и бота и перезапускает упавшие процессы,
`restart.sh` управляет ими:

```bash
./restart.sh            # перезапустить бота и анализатор, адрес приложения прежний
./restart.sh tunnel     # то же с новым туннелем
./restart.sh stop       # остановить всё
```

Бот собирается под Linux на любой машине:

```bash
cd bot && GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -o keyscout-bot .
```

Если DNS сервера отдаёт заблокированный адрес Telegram, адрес API можно закрепить:
`TELEGRAM_API_IP=149.154.167.220` — сертификат `api.telegram.org` при этом проверяется как обычно.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | приветствие и настройка |
| `/menu` | настройки: слова, источники, почта, период, автообновление |
| `/search` | отчёт прямо сейчас |
| `/report` | отчёт на почту |
| `/id` | свой ID в Telegram |
| `/export` | журнал поисков в Excel, только для администраторов из `ADMIN_IDS` |

## API анализатора

| Метод | Что делает |
|---|---|
| `POST /search` | итоги, выжимка и картинка отчёта |
| `POST /report` | то же и письмо на почту |
| `POST /dashboard` | данные для веб-приложения: итоги, выжимка, все найденные материалы |
| `POST /expand` | варианты написания слов |
| `GET /sources` | каталог источников |
| `GET /log.xlsx` | журнал поисков |

Документация: http://localhost:8000/docs
